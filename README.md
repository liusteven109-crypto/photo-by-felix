# Photo by Felix

Felix 的两场摄影展，共用一个 GitHub Pages 站点。

- [光影诗集](https://liusteven109-crypto.github.io/photo-by-felix/)：原有的 47 张摄影作品。
- [窗光作品展](https://liusteven109-crypto.github.io/photo-by-felix/window-light/)：40 张作品，按风景（8）、人文（12）、光影（8）、人像（12）四章展开，包含 6 张窗光人像。

## 发布

GitHub Pages 从 `main` 分支根目录发布。修改对应目录并推送后会自动更新。首页为 `index.html`，窗光版为 `window-light/index.html`。资源使用相对路径，两个版本可以独立维护。

## 2026-09-19 展览编排

窗光版以「从远方，到身旁」为主题。桌面按原始宽高比对齐组图，图间距 22px、行间距 28px；手机横幅单列、相邻竖幅成对。章节目录固定在顶部，点击照片后按当前章节顺序浏览。原有光影诗集保留。
